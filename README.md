# 🎬 Netflix Content Intelligence Dashboard  
### Turning Netflix Data into Smart Entertainment Insights

---

## 🌟 Project Story
Netflix has thousands of movies and TV shows across different countries, genres, ratings, and years.  
This project transforms raw Netflix data into an interactive **Content Intelligence Dashboard** that helps users explore patterns, trends, and hidden insights behind Netflix’s content library.

Along with visual analytics, this project also uses **Machine Learning** to group similar titles based on descriptions.

## 🎯 What This Project Solves
This project answers questions like:

- Which type of content dominates Netflix: Movies or TV Shows?
- Which countries contribute the most content?
- What are the most common genres?
- How has Netflix content grown over the years?
- Which ratings are most common?
- Can we group similar Netflix titles using Machine Learning?
